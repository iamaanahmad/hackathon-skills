# Pitch Framework

Sequence: Problem -> Innovation -> Proof -> Impact.

Default 180s structure:
- 0-10s: problem
- 10-25s: current gap
- 25-45s: solution
- 45-90s: live magic moment
- 90-120s: technical depth
- 120-150s: sponsor value
- 150-180s: impact + close

Keep claims evidence-backed and concise.
